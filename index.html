Panduan Instalasi

Ikuti langkah berikut sampai game siap dimainkan.

1

Download APK dan ROM

Download kedua file dari tombol di atas. Pastikan file ROM bernama
Super Mario Bros.nes

2

Izinkan instalasi aplikasi

Jika Android meminta izin, buka Settings atau Pengaturan → Security & Privacy → Install unknown apps, lalu izinkan instalasi dari aplikasi yang digunakan untuk membuka APK. Nama menu dapat berbeda sesuai merek HP.

3

Instal aplikasi

Buka File Manager → Downloads. Ketuk file APK yang sudah diunduh, lalu pilih Install atau Instal.

4

Pilih file ROM game

Buka aplikasi SMB Remastered. Jika muncul pesan ROM VERIFICATION REQUIRED, pilih file Super Mario Bros.nes dari penyimpanan HP.

5

Mulai bermain!

Setelah ROM berhasil diverifikasi, ikuti petunjuk di aplikasi dan nikmati permainan Super Mario Bros.

💡

ROM tidak terbaca?
Pastikan file ROM sudah terunduh sepenuhnya dan pilih file yang benar, bukan file ZIP atau file lain. Jika masih gagal, coba download ulang.
