📖 Panduan Instalasi

1

Unduh Kedua File

Tekan tombol Download APK dan Download ROM di atas. Simpan kedua file di penyimpanan HP kamu.

File yang dibutuhkan:

  • File aplikasi SMB Remastered Android (.apk)
  • Super Mario Bros.nes
2

Izinkan Instalasi Aplikasi

Jika Android meminta izin untuk memasang aplikasi, buka pengaturan yang ditampilkan pada layar.

Pada sebagian perangkat, menu ini berada di Settings → Security & Privacy → Install unknown apps.

Pilih aplikasi yang digunakan untuk membuka file APK, misalnya File Manager atau browser, lalu aktifkan izin instalasi jika diperlukan.

Nama dan lokasi menu dapat berbeda tergantung merek serta versi Android.

3

Instal Aplikasi

Buka File Manager di HP kamu, lalu masuk ke folder tempat file APK diunduh. Biasanya file berada di folder Download.

Ketuk file APK SMB Remastered, tekan Install, kemudian tunggu sampai proses instalasi selesai.

Setelah selesai, buka aplikasi SMB Remastered.

4

Pilih File ROM

Saat aplikasi menampilkan pesan ROM VERIFICATION REQUIRED, ketuk pesan atau tombol yang tersedia untuk memilih ROM.

Buka lokasi file ROM yang sudah diunduh, lalu pilih Super Mario Bros.nes.

Tunggu proses pemeriksaan file selesai. Jika berhasil, lanjutkan ke permainan.

5

Mulai Bermain

Setelah ROM berhasil dikenali oleh aplikasi, kamu bisa mulai memainkan SMB Remastered di perangkat Android.

❓ Kendala Saat Instalasi?

File ROM tidak ditemukan

Pastikan file Super Mario Bros.nes sudah diunduh dan kamu memilih file yang benar melalui pemilih file Android.

Pesan ROM Verification masih muncul

Periksa kembali apakah file ROM yang dipilih benar dan proses pemilihan file sudah selesai. Jika masih gagal, coba unduh ulang file ROM.

APK tidak bisa dipasang

Periksa apakah file APK sudah selesai diunduh dan apakah perangkat mengizinkan pemasangan aplikasi tersebut. Jika muncul pesan kesalahan, perhatikan pesan yang ditampilkan Android.
