Panduan Instalasi

Ikuti langkah-langkah berikut

1

Download kedua file

Tekan tombol Download APK dan Download ROM di atas. Pastikan kedua file sudah tersimpan di HP.

  • SMB Remastered Android (.apk)
  • Super Mario Bros.nes
2

Izinkan instalasi aplikasi

Jika diminta, buka pengaturan Android untuk mengizinkan pemasangan aplikasi dari sumber tersebut.

Pada beberapa perangkat, menu ini ada di Settings → Security & Privacy → Install unknown apps. Nama menu bisa berbeda tergantung merek dan versi Android.

3

Instal SMB Remastered

Buka File Manager, masuk ke folder Download, lalu ketuk file APK. Tekan Install dan tunggu sampai selesai.

Setelah selesai, buka aplikasinya.

4

Pilih file ROM

Saat muncul pesan ROM VERIFICATION REQUIRED, ketuk pesan atau tombol untuk memilih file.

Cari lalu pilih Super Mario Bros.nes dari penyimpanan HP.

5

Mulai bermain

Tunggu proses pemeriksaan ROM selesai. Jika file berhasil dikenali, kamu bisa melanjutkan ke permainan.

💡 ROM tidak terbaca?

Pastikan file ROM terunduh lengkap dan pilih file yang benar. Jika masih gagal, coba unduh ulang file ROM kemudian pilih kembali.
