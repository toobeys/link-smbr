Panduan Instalasi

1

Download File

Download kedua file melalui tombol di atas:

  • SMB Remastered Android (.apk)
  • Super Mario Bros.nes
2

Izinkan Instalasi APK

Jika diminta, buka pengaturan Android dan izinkan pemasangan aplikasi dari sumber tersebut.

Pada beberapa HP, menu berada di Settings → Security & Privacy → Install unknown apps. Nama menu bisa berbeda tergantung perangkat.

3

Instal Aplikasi

Buka File Manager, masuk ke folder Download, lalu ketuk file APK. Tekan Install dan tunggu sampai selesai.

Setelah itu, buka SMB Remastered.

4

Pilih File ROM

Ketika muncul pesan ROM VERIFICATION REQUIRED, ketuk pesan atau tombol untuk memilih file ROM.

Cari dan pilih Super Mario Bros.nes dari penyimpanan HP.

5

Mulai Bermain

Tunggu pemeriksaan ROM selesai. Jika file berhasil dikenali, lanjutkan dan nikmati permainannya.

💡 Jika ROM Gagal Dibaca

Pastikan file ROM sudah terunduh dengan lengkap dan pilih file yang benar. Jika masih gagal, coba unduh ulang ROM lalu pilih kembali melalui aplikasi.
